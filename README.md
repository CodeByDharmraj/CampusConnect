
# CampusConnect

A centralized academic information and campus activity portal.

## Problem

Academic information is scattered across platforms such as Moodle,
messaging groups, and email. Students may miss important notices,
workshops, timetable changes, and deadlines.

## MVP Goals

- Role-based access for students, faculty, and administrators
- Centralized announcements with read/unread status
- Course and attendance management
- Assignment creation and submissions
- Responsive user interface

## Planned Technology

- Frontend: React and Vite
- Backend: Node.js and Express
- Database: MongoDB and Mongoose
- Version control: Git and GitHub

## Project Structure

- `docs/` — project documentation
- `client/` — web application
- `server/` — API server
